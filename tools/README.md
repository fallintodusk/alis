# Public Tools

The public developer release contains the engine-independent World toolchain.

- [World tools](World/README.md) - bootstrap, source ingestion, canonical
  compilation, validation, and Unreal realization routes.

Build Service, Launcher, private automation, and deployment tooling are not
part of the public source projection. Their absence does not affect the
promised Kazan and Manhattan developer route.

For project compilation and testing, use the [build router](../docs/build/README.md)
and [testing router](../docs/testing/README.md).
