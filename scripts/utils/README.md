# Utility Scripts

Small standalone utilities that do not belong to an Unreal subsystem.

| Need | Entry point |
|---|---|
| Normalize text files | `sanitize_text.py` |
| Generate placeholder textures | `generate_placeholder_textures.py` |

The `generate_placeholder_textures_fast.py` and
`generate_placeholder_textures_simple.py` variants are specialized entry
points for the same placeholder-texture task.
