# Plugins

First-party ALIS runtime, editor, test, and World components grouped by ownership tier.

| Tier | Owner |
|---|---|
| Early boot | [Boot](Boot/README.md) |
| Editor-only integration | [Editor](Editor/README.md) |
| Domain capabilities | [Features](Features/README.md) |
| Cross-component contracts and primitive types | [Foundation](Foundation/README.md) |
| Game-mode and gameplay composition | [Gameplay](Gameplay/README.md) |
| Reusable content-facing resources | [Resources](Resources/README.md) |
| Reusable runtime services | [Systems](Systems/README.md) |
| Cross-component automation | [Test](Test/README.md) |
| Shared and domain presentation | [UI](UI/README.md) |
| World generation, realization, and World data | [World](World/README.md) |

Bundled third-party plugins and machine-local tooling are dependencies, not
first-party architecture owners, and are excluded from the public source projection.
