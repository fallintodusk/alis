# Structural realization structure

## Boundary

This editor leaf realizes the canonical structural field without fitting it or
adding a presentation lift. Canonical Compilation owns geographic correction,
source qualification and model policy. The shared World loader projects verified
face regions, gangway axes and numeric policy into the typed input contract.

## Dependencies and persistence

The existing World registry, material context, native mesh builder and outer
transaction remain authoritative. This leaf consumes no Terrain height field.
Its dependency unit is the canonical cell; separate feature/cell packages allow
unchanged meshes inside a dirty cell to be reused. Successful empty clips remain
explicit boundary contacts without physical artifacts; unreadable or failed
conversion refuses.

Dependency hashing validates complete source fields, policy, membership and
coordinate frames without constructing native mesh descriptions. Cell identities
consume geometry, model semantics, role/axis policy, clipping bounds and the join
limit. Receipt-only admission metadata participates in verification evidence,
without dirtying physical output. Unconsumed Terrain does not enter this identity.

Apply and artifact capture still construct and qualify expected native output,
then compare actual saved geometry and attributes. Their per-output binding
includes the regenerated geometry hash and model identity; it is distinct from
the semantic cell dependency hash. Hash success certifies source preparation,
not float-storage realizability. Native conversion and stored slope failures
refuse during the full plan before output mutation. An unchanged saved mesh can
be reused even when model-bound actor metadata needs updating.

Actual stored triangles retain their original source ordinals. Region-specific
slope checks use that correspondence, with each gangway's own projected axis.
The leaf consumes the existing road material binding and supplies physical
collision and navigation geometry. The
[shared producer contract](../../../../docs/territory_contract.md#add-or-change-a-layer-producer)
owns registration, verification, transactions and authority. Per-record output
does not establish cross-record joins or a complete gameplay route.
