# Small building neighborhood

Owns a seven-building, two-cell synthetic lifecycle fixture. The first rectangle
retains the approximately 15.83 x 5.37 m footprint and 7.5 m height used by the
captured Manhattan building proof; the other rectangles exercise independent
selections, an unaffected cell and an unselected crossing. Coordinates, shallow synthetic DSM and IDs are
fixture data, not a surveyed neighborhood or bare-earth claim.
