# Release ALIS 2.0.0

**Status:** Complete

**Stable owner:** [Package and Release Guide](../../../docs/build/packaging_guide.md)

## Outcome

- The signed ALIS 2.0.0 release is published on GitHub at tag `v2.0.0`.
- The signed `game/` and flat `github/` projections passed their release
  verification routes before publication.

The reusable itch publisher remains available for a future authorized release;
the external refusal does not keep ALIS 2.0.0 open.
