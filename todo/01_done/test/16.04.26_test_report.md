## Runtime Crash — RESOLVED

**Crash:** `EXCEPTION_ACCESS_VIOLATION reading address 0x0000000000000004`
**Crash IDs:** `UECC-Windows-BA651...`, `UECC-Windows-12B90...`
**Analysis:** [analyze_dump.ps1](../../scripts/debug/analyze_dump.ps1) via cdb.exe

```
Crash point: AnimationCore::SolveTwoBoneIK+0x29d
  movss xmm0, dword ptr [rax+rdi*4]   // rax=0 (NULL), rdi=1 → address 0x4

Call stack:
  SolveTwoBoneIK → SolveCCDIK → FAnimNode_CCDIK::EvaluateSkeletalControl
  → ULocalFirstPersonCapability::ApplyVisibility (line 329)
  → OnMutableInstanceUpdated (line 419) → UCustomizableObjectSystem::TickInternal
```

**Root cause:** `RotationLimitPerJoints` array empty. Engine reads it unconditionally in `CCDIK.cpp:31` before checking `bEnableRotationLimit`. Empty array = null pointer = crash.
**Fix:** F1/F2 — fill array via reflection in [LocalBodyCorrectionChainIK.cpp:35-51](../../Plugins/Gameplay/ProjectSkeletalCapabilities/Source/ProjectSkeletalCapabilities/Private/LocalBody/LocalBodyCorrectionChainIK.cpp#L35-L51) (editor-only method unavailable in Shipping).

## Asset Cooking — RESOLVED

**Problem:** Character had no animation and no mesh in packaged builds.

Runtime log (before fix):
```
SkipPackage: /ProjectSkeletalCapabilities/MotionMatching/ABP_MotionMatchingBridge — does not exist
SkipPackage: /ProjectObject/Human/Hero/COI_Hero — does not exist
[InteractionComponent] SetupPostProcess: No CameraComponent found on owner 'DefinitionCharacter'
```

Runtime log (after fix F4):
```
[MotionMatching] Installed PostProcess bridge 'ABP_MotionMatchingBridge_C' on DriverBody
[MutableCustomization] COI updated on 'DefinitionCharacter' - 3 CSKs active
[MutableCustomization] Post-rebuild: 'BodyCustomization', 'HeadCustomization', 'LocalBodyCustomization'
[MutableCustomization] Promoted WorldBody visual source: WorldBodyMesh=SK_CO_Character_Body AnimClass=ABP_WorldBodyRetarget_C
```

**Root cause:** Both assets loaded dynamically via `LoadObject()` in [MotionMatchingCapability.cpp:179](../../Plugins/Gameplay/ProjectSkeletalCapabilities/Source/ProjectSkeletalCapabilities/Private/MotionMatchingCapability.cpp#L179) and `LoadSynchronous()` in [MutableCustomizationCapability.cpp:333](../../Plugins/Gameplay/ProjectSkeletalCapabilities/Source/ProjectSkeletalCapabilities/Private/MutableCustomizationCapability.cpp#L333) — cooker can't discover them.
**Fix:** F4 — `+DirectoriesToAlwaysCook` in [DefaultGame.ini:51-52](../../Config/DefaultGame.ini#L51-L52).
