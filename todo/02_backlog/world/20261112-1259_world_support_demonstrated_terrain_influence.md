# Support a demonstrated Terrain influence consumer

Status: BACKLOG - conditional; no implementation until an actual generator
requires a Terrain adjustment not served by the existing authored correction.

## Scope

The accepted direction allows a later road, bridge, building or manual consumer
to request bounded Terrain adaptation. Canonical correction remains the single
Terrain authority; generated object meshes do not become another writer.
Existing authored patches and declared canonical operations are the first tools
to try. This task does not authorize a PCG framework, general scenario engine,
editor sculpt UI or new geographic model.

Ordinary object reconstruction first uses final Terrain for placement/support.
Approximate contextual prototypes alone do not establish a need for this API.
Resume only for a demonstrated residual that existing corrections cannot serve;
do not reopen completed Ground investigations merely to improve object detail.

## Trigger and acceptance

- Name the real consumer, its failing input, required support/clearance and
  residual that existing operations cannot represent.
- Capture the smallest source-faithful RED fixture before extending the owner.
- Add only the demonstrated request/response seam or dependent correction;
  preserve explicit source versus authored provenance and unresolved data.
- Prove deterministic reconstruction, refusal/no mutation, unaffected neighbors,
  exact dirty scope and measured local execution. Recheck only affected consumers.
- Compare the installed PCG MeshPartition Query/Write and patch/projection
  spawners for that consumer. Distinguish foliage placement/exclusion from actual
  Terrain modification, and editor-baked work from required runtime behavior.
  Resolve feedback/order and canonical-adapter ownership before allowing writes.
  The researched native options and accepted integration direction live in the
  stable Terrain/feature owner below; do not start a PCG implementation to close
  the current Terrain baseline or demand perfect source constructions first.

Stable owners: [Terrain and feature separation](../../../Plugins/World/ProjectWorld/docs/territory_contract.md#terrain-and-feature-separation)
and [canonical refinement](../../../tools/World/CanonicalCompilation/refinement/docs/architecture/structure.md).
