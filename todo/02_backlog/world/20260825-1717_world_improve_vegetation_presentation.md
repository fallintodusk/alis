# Improve Generated Vegetation Presentation

Status: uninvestigated

## Current gap

Generated vegetation has deterministic cell-owned placement but limited visual
variety and semantic coverage.

## Investigation boundary

- Preserve canonical records, deterministic seeds, cell ownership, collision,
  exclusions, generated identity, and the accepted HISM representation unless
  measurements justify a separate change.
- Evaluate palette variety, missing non-tree semantics, and density as separate
  candidates in that order.
- Keep ProjectWorld as realization owner, ProjectObject as mesh owner, and
  territory data as concrete configuration owner.
- Prove regeneration locality, packaged visuals, traversal, and frame budget.

Start from [ProjectWorld architecture](../../../Plugins/World/ProjectWorld/docs/architecture/README.md).
