# Save/Load System

Local user progress persistence for single play mode.

## Scope

- [ ] Inventory state (grid layout, item stacks, equipped items)
- [ ] Quest progress (active, completed, failed)
- [ ] Dialogue state (conversation history, branching choices)
- [ ] Vitals (health, stamina, calories, hydration, fatigue)
- [ ] Thought history
- [ ] Player position and world state
